Como usar

  • Nada é baixado em massa: as miniaturas são geradas pelo pCloud e só carregam quando entram na tela.
  • Vídeos abrem em streaming. Use os botões de resolução para economizar dados (480p/720p) ou ver no original.
  • Atalhos: ← → navegam, F tela cheia, D baixar, Esc fecha.
  • Uploads vão para a pasta aberta, com barra de progresso.

Se a lista não carregar

O navegador precisa permitir chamadas para api.pcloud.com. No GitHub Pages isso funciona. Se testar local por file:// e falhar, rode um servidor local (python -m http.server) ou use o link publicado.
